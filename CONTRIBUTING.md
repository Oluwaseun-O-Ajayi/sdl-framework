# Contributing to SDL Framework

Thank you for your interest in improving SDL Framework.

## Reporting bugs and asking questions

Open an issue at https://github.com/Oluwaseun-O-Ajayi/sdl-framework/issues. For bugs, include the Python version, operating system, the code you ran and the full error message. The author aims to respond within two weeks.

## Proposing changes

1. Fork the repository and create a branch from `main`.
2. Install the package with test dependencies: `pip install -e ".[test]"`.
3. Make your change and add or update tests in `tests/`.
4. Run `python -m pytest` and confirm that all tests pass.
5. Open a pull request that describes what changed and why.

New features should come with tests and, where relevant, an example or documentation update. Please keep pull requests focused on one change.

## Code of conduct

Be respectful and constructive. Harassment or personal attacks are not tolerated.
